# Hybrid Portfolio — Aviation Engineering & Technopreneurship

Personal portfolio website for Y.A. Prasetya Putra, S.T., combining aviation engineering experience with technopreneurship reflections.

## Contents

- **About Me** — professional profile and CV infographic. Personal information has been redacted for public display.
- **Aviation Career** — work experience timeline and additional professional roles.
- **Technical Expertise** — aircraft types, systems, licenses, and professional competencies.
- **Innovation & Vision** — direction for safer, more reliable, and technology-enabled aircraft maintenance.
- **Technopreneurship reflections** — the original eight reflection sections and complete manuscript are retained.

## Files

- `index.html` — complete responsive website.
- `about-me-redacted.png` — CV infographic with personal details masked.
- `README.md` — this guide.

The Elon Musk Character-tab image is embedded directly in `index.html`.

## Run locally

Open `index.html` in a modern browser. Keep `about-me-redacted.png` in the same folder as `index.html`.

## Publish with GitHub Pages

1. Upload `index.html`, `about-me-redacted.png`, and `README.md` to the repository root.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Open the published Pages URL after deployment completes.

## Privacy notes

The public CV image intentionally masks birth details, gender, marital status, religion, home address, phone number, and email. License numbers and examination identifiers are not repeated in the website text. Review all information before making the repository public.

## Image notes

The About Me infographic is included as a local image. Several aviation tab visuals and the hero background in the original reflection website use remote image URLs and therefore require an internet connection.
